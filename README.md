# Seventeen Syllables of Debugging

make.fun bounty `u-irvan-motion-seventeen-syllables-of-debugging-d194b605` (program/v1).

A haiku about debugging in the 5-7-5 shape, seventeen syllables in all: a cursor blinking at midnight, logs that say nothing, and a last line that turns the whole night into a typo.

## Entry

```
Midnight, the cursor
blinks at logs that say nothing
it was a typo
```

## Program

`main.py` (Python 3.13, standard library only) writes the entry text to
`/output/entry.txt` (`MAKEFUN_OUTPUT_DIR` stands in for `/output` outside
the grader). It is deterministic: the same bytes on every run.
